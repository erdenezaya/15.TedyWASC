# WACE Computer Science — Year 11 ATAR Exam Prep

Units 1 & 2 шалгалтын бэлтгэлийн статик сайт. Ойлголтыг монголоор тайлбарлаж, шалгалтын хариултыг англиар, marker-ийн хайдаг keyword-тайгаар сургана.

## Агуулга
- **Сэдвүүд**: 32 сэдэв. Тус бүрт монгол тайлбар, зүйрлэл, англи keyword, шалгалтын хэв маягийн асуулт, онооны дагуу загвар хариулт, түгээмэл алдаа бий.
- **Өөр хэлбэрээр асуувал**: жишээ шалгалтад ороогүй ч ижил ойлголтыг өөр хувилбар, өөр command word-оор шалгах асуултууд.
- **Санамсаргүй дадлага**: бүх асуултаас санамсаргүй сонгоно. Өөрийгөө дүгнэхэд сул сэдвүүд тодорно.
- **Код**: Python/pseudocode/SQL даалгавар. Hint болон онооны шалгууртай.
- **Quiz, Flashcards, Command words**.

## Бүтэц
```
index.html   — хуудасны бүтэц
styles.css   — загвар (light/dark)
app.js       — hash router ба харагдацууд
data.js      — бүх агуулга (TOPICS, VARIANTS, QUIZ, CODE_TASKS)
PROJECT_PROMPT.md — Claude Project-ийн instructions
```

## Агуулга нэмэх
`data.js` доторх `TOPICS`-д шинэ сэдэв, `VARIANTS[topicId]`-д шинэ асуулт, `QUIZ`-д олон сонголттой асуулт нэмнэ. Build алхам шаардлагагүй.

## Анхааруулга
- Шалгалтын эх PDF repo-д ороогүй. Асуултууд өөрийн үгээр бичигдсэн.
- Creature Keeper-ийн game loop ба 3NF ERD нь source booklet-гүйгээр бичигдсэн. Wellbeing-ийн томьёо болон flat file хүснэгтийг booklet-тэй тулгаж шалгаарай.

## Ажиллуулах
`index.html`-ийг браузерт нээнэ, эсвэл `npx serve .` ажиллуулна. Vercel дээр статик сайт байдлаар deploy хийгдэнэ.
